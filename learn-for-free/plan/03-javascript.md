## Learning path (source order)
**Part 1 – The JavaScript language**
1. Introduction / manuals & specs / code editors / developer console — /intro

3. Variables, data types, interaction, type conversions — /variables /types
4. Operators, comparisons, conditionals, logical operators, nullish coalescing — /operators
5. Loops (while/for), switch — /while-for
6. Functions: basics, expressions, arrow functions — /function-basics
7. Code quality: debugging, comments, testing with Mocha — /code-quality
8. Objects: basics, references/copying, methods, `this`, `new`, optional chaining, symbols — /object-basics
9. Data types: primitives methods, numbers, strings, arrays, array methods, iterables, Map/Set, WeakMap/WeakSet, destructuring, Date, JSON — /data-types
10. Advanced functions: recursion, rest/spread, closures, `var`, function object, scheduling, call/apply, bind — /advanced-functions
11. Property flags & descriptors, getters/setters — /object-properties
12. Prototypes and inheritance — /prototypes
13. Classes: syntax, inheritance, static, private, instanceof, mixins — /classes
14. Error handling: try..catch, custom errors — /error-handling
15. Promises, async/await, callbacks, microtasks — /async
16. Generators, async iteration — /generators-iterators
17. Modules: import/export, dynamic imports — /modules
18. Miscellaneous: Proxy/Reflect, currying, BigInt, WeakRef — /js-misc

**Part 2 – Browser: Document, Events, Interfaces**
19. Document: browser environment, DOM tree, walking/searching the DOM, node properties, attributes vs properties, modifying the document, styles & classes, sizes, coordinates — /document
20. Events: introduction, bubbling/capturing, delegation, default actions, dispatching custom events — /events
21. UI events: mouse, pointer, keyboard, scrolling — /event-details
22. Forms and controls: properties/methods, focus/blur, change/input, submit — /forms-controls
23. Loading: DOMContentLoaded, async/defer, resource onload/onerror — /loading
24. Miscellaneous: MutationObserver, Selection/Range, event loop — /ui-misc

**Part 3 – Additional articles**
25. Frames & windows, binary data/files, network requests (fetch, XHR, WebSocket, SSE) — /network
26. Storing data: cookies, localStorage/sessionStorage, IndexedDB — /data-storage
27. Animation, web components, regular expressions — /regular-expressions
