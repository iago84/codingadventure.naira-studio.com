## Flags / issues
- All content is reachable and public; no login, no paywall, and no JS-only gating of the TOC.
- The docs TOC is large (~74 entries in 9 sections) and was summarised by section rather than reproduced line by line; item numbers above are a flattened, grouped view of the source order.
- Microsoft copyright applies; text and illustrations must not be copied — only short topic names are used here.
- The Handbook page mixes current and legacy paths (the `/docs/handbook/2/` prefix marks the 2nd-edition handbook, while some Reference pages point at older first-edition URLs); the volume should target the `/2/` handbook and note where Reference pages lag behind.
- Release notes on the page point at newer TypeScript versions (e.g. "What's new in 7.0"); verify the version targeted when writing chapters, since decorators and compiler flags change between majors.
- Some Reference items (namespaces, triple-slash directives, mixins) are legacy features; include them but mark them as such rather than presenting them as modern practice.
