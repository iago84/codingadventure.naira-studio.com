# Plan for Vol. 43 - Generative AI (Kaggle)

**Source:** https://www.kaggle.com/learn/generative-ai
**Status:** planned
**Access:** reachable, gated (free account / Kaggle login required)

## Approach

The Kaggle "Generative AI" micro-course introduces text generation with large
language models. This volume covers the same topics with original explanations,
self-contained code using the OpenAI API (with a free tier) and exercises that
run without a Kaggle account.

## Chapter list

| # | Chapter | Topics |

| 1 | What is generative AI? | definition, examples, capabilities |
| 2 | Large language models | what they are, how they work at a high level |

| 4 | Your first prompt | simple text generation, temperature |
