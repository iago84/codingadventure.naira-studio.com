# Plan for Vol. 39 - Deep Learning (Kaggle)

**Source:** https://www.kaggle.com/learn/intro-to-deep-learning
**Status:** planned
**Access:** reachable, gated (free account / Kaggle login required)

## Approach

The Kaggle "Intro to Deep Learning" course introduces neural networks with
TensorFlow/Keras, image data, and basic computer vision. This volume covers the
same topics with original explanations, self-contained code and a smaller,
self-made dataset so nothing is copied.

## Chapter list

| # | Chapter | Topics |
|---|---------|--------|
| 1 | Why deep learning? | what neural networks are, when they help |
| 2 | Neural networks from scratch | neurons, weights, activation functions |
| 3 | Training with TensorFlow | Keras Sequential API, Dense layers |
| 4 | Image data and labels | pixels, classes, loading images |
| 5 | Convolutional layers | filters, feature maps, pooling |
| 6 | Building a CNN | layers, dropout, data augmentation |
| 7 | Overfitting and regularisation | dropout, weight decay, early stopping |
| 8 | Transfer learning | pre-trained models, fine-tuning |
| 9 | Working with small data | augmentation, feature extraction |
| 10 | Saving and exporting models | model formats, deployment basics |
| 11 | Where to go next | RNNs, transformers, production tips |

## Fallback

All content is original writing. All code is written from scratch using
TensorFlow/Keras; no Kaggle notebook is reproduced. A small synthetic image
dataset is used where the Kaggle course uses a larger one.
