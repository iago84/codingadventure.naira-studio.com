# Plan for Vol. 41 - Stanford Machine Learning (CS229)

**Source:** https://cs229.stanford.edu/
**Status:** planned
**Access:** reachable, free (public course page and lecture videos)

## Approach

Stanford's CS229 is the classic Andrew Ng machine learning course. This volume
covers the same syllabus with original explanations, self-contained code and
original exercises. The math is explained step by step, not skipped.

## Chapter list

| # | Chapter | Topics |

| 2 | Linear regression | cost function, gradient descent, normal equation |
| 3 | Logistic regression | classification, decision boundary, cost |
| 4 | Regularisation | L1/L2, bias-variance tradeoff |
| 5 | Neural networks | representation, forward pass, backprop |
| 6 | Advice for ML | debugging, learning curves, error analysis |
| 7 | Support vector machines | kernels, margins, soft margin |

| 13 | Where to go next | advanced topics, research directions |
