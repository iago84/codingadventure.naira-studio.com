- Source site: https://learn.microsoft.com/azure/ (plus https://learn.microsoft.com/en-us/training/azure/)

- Access: reachable
- Notes: Microsoft Learn is server-rendered and public. The training browse page is JS-rendered and returned no items.

## Learning path (source order)
1. **Azure Overview** — What Azure is: web apps, VMs, storage, databases, identity, AI/IoT services — https://learn.microsoft.com/azure/
2. **Get started for Azure developers** — Developer-focused onboarding to Azure docs and tools — https://learn.microsoft.com/azure/developer/
3. **Microsoft Azure Fundamentals: describe cloud concepts** — First learning path of the AZ-900 track (cloud concepts) — https://learn.microsoft.com/training/paths/microsoft-azure-fundamentals-describe-cloud-concepts/
4. **Instructor-led course AZ-900T00** — Classroom/virtual Azure Fundamentals course — https://learn.microsoft.com/training/courses/az-900t00
5. **AZ-900 certification practice assessment** — Readiness check before the fundamentals exam — https://learn.microsoft.com/credentials/certifications/exams/az-900/practice/assessment
6. **Architecture Center** — Design guidance and reference architectures for Azure apps — https://learn.microsoft.com/azure/architecture/
7. **Cloud Adoption Framework** — Methodology for adopting Azure at organizational scale — https://learn.microsoft.com/azure/cloud-adoption-framework/
8. **Azure Well-Architected Framework workloads** — Reliability, security, cost, operations, performance pillars — https://learn.microsoft.com/azure/architecture/
9. **Browse all Azure training** — Role-based paths beyond fundamentals (administration, development, architecture, DevOps) — https://learn.microsoft.com/training/browse/?products=azure
10. **Microsoft Virtual Training Days** — Free instructor-led skilling events — https://events.microsoft.com/mvtd-azure
