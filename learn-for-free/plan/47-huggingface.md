# Plan for Vol. 47 - Hugging Face Docs

**Source:** https://huggingface.co/docs
**Status:** planned
**Access:** reachable, free (public documentation)

## Approach

The Hugging Face documentation is the reference for the Transformers ecosystem.
This volume covers the same topics with original explanations, self-contained
code and exercises that run on CPU or a free GPU.
