# Plan for Vol. 36 - Python for AI (Kaggle)

**Source:** https://www.kaggle.com/learn/python
**Status:** planned
**Access:** reachable, gated (free account / Kaggle login required for course content)

## Approach

Kaggle Learn courses are interactive notebooks behind a login wall. The free
"Python" course covers the core data science Python stack. This volume will
cover the same topics from scratch, with original explanations and self-contained
examples that run without a Kaggle account.

## Chapter list (from the Kaggle Python course)

| # | Chapter | Topics |
|---|---------|--------|
| 1 | Python basics | variables, types, arithmetic, input/output |
| 2 | Conditionals and loops | if/elif/else, for, while, break, continue |
| 3 | Functions | definition, arguments, return, scope, lambdas |
| 4 | Lists and tuples | indexing, slicing, methods, list comprehensions |

| 13 | Project: exploring the data | end-to-end notebook walkthrough |
| 14 | Where to go next | more Kaggle courses, further reading |

## Fallback

All content is original writing. Kaggle's interactive environment is not
reproducible in a static PDF; every example is written to run with plain
Python 3 + pandas + numpy on any machine.
