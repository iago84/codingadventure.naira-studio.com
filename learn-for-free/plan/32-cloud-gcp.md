# Vol. 32 – Cloud (GCP) – Study Plan

- Source site: https://www.cloudskillsboost.google (plus https://cloud.google.com/learn/training and https://cloud.google.com/learn/certificates)
- Fetched: 2026-10-10
- Access: js-only (homepage/catalog render client-side; course list not fetchable — supplementary official pages on cloud.google.com/learn were used)
- Notes: Google Skills platform catalog is JavaScript-rendered ("Loading...", "No results found" in fetched HTML); public learning structure was taken from cloud.google.com/learn pages. Free access via GEAR (35 monthly credits), student credits, and many free skill-badge labs; certificate paths need a $29/month subscription.

## Learning path (source order)
1. **Google Cloud Computing Foundations Certificate path** — 4-course beginner path over cloud, big data, and ML basics — https://www.cloudskillsboost.google/paths/36
2. **Google Cloud Engineering Certificate path** — 6-course intermediate path to plan, configure, and deploy cloud solutions — https://cloud.google.com/learn/certificates
3. **Google Cloud Data Analytics Certificate path** — 5 courses with 15 labs for the Cloud Data Analyst role — https://www.cloudskillsboost.google/paths/420
4. **Google Cloud Cybersecurity Certificate path** — 5 courses with 12 labs for the Cloud Cybersecurity Analyst role — https://www.cloudskillsboost.google/paths/419
5. **Hands-on labs with temporary credentials** — Labs that provision real Google Cloud resources — https://www.cloudskillsboost.google/catalog?format[]=labs
6. **Learning paths by role/use case** — Guided journeys of curated courses and labs — https://www.cloudskillsboost.google/catalog?format[]=learning_plans
7. **Skill badges** — Credentials proving hands-on GCP knowledge (e.g., agents, Kubernetes, BigQuery) — https://www.cloudskillsboost.google/catalog?skill-badge[]=skill-badge
8. **Featured path: Introduction to Agents and Google's Agent Ecosystem** — AI agents fundamentals, ends in a skill badge — https://www.skills.google/paths/3546
9. **Generative AI Leader learning path** — Gen AI overview through organizational transformation — https://www.skills.google/paths/1951
10. **Google Cloud certifications (exams)** — Associate Cloud Engineer, Professional Cloud Architect/DevOps/Data Engineer, etc. — https://cloud.google.com/learn/certification
