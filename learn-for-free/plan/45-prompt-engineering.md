# Plan for Vol. 45 - Prompt Engineering

**Source:** https://learnprompting.org/
**Status:** planned
**Access:** reachable, free (public website)

## Approach

Learn Prompting is a free, community-maintained guide to prompt engineering.
This volume covers the same topics with original explanations, self-contained
examples using the OpenAI API (free tier) and exercises that run without any
special access.
