## Learning path (source order)
1. **Getting Started** — about version control, history of Git, the command line, installing, first-time setup, getting help — https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control
2. **Git Basics** — getting a repository, recording changes, viewing history, undoing things, remotes, tagging, aliases — https://git-scm.com/book/en/v2/Git-Basics-Getting-a-Git-Repository
3. **Git Branching** — branches, branching and merging, branch management, branching workflows, remote branches, rebasing — https://git-scm.com/book/en/v2/Git-Branching-Branches-in-a-Nutshell
4. **Git on the Server** — protocols, setting up a server, SSH keys, Git daemon, smart HTTP, GitWeb, GitLab, third-party hosting — https://git-scm.com/book/en/v2/Git-on-the-Server-The-Protocols
5. **Distributed Git** — distributed workflows, contributing to and maintaining a project — https://git-scm.com/book/en/v2/Distributed-Git-Distributed-Workflows
6. **GitHub** — account setup, contributing, maintaining projects, organizations, scripting GitHub — https://git-scm.com/book/en/v2/GitHub-Account-Setup-and-Configuration
7. **Git Tools** — revision selection, interactive staging, stashing/cleaning, signing, searching, rewriting history, reset demystified, advanced merging, rerere, debugging, submodules, bundling, replace, credential storage — https://git-scm.com/book/en/v2/Git-Tools-Revision-Selection
8. **Customizing Git** — configuration, attributes, hooks, enforced-policy example — https://git-scm.com/book/en/v2/Customizing-Git-Git-Configuration
9. **Git and Other Systems** — Git as a client, migrating to Git — https://git-scm.com/book/en/v2/Git-and-Other-Systems-Git-as-a-Client
10. **Git Internals** — plumbing vs porcelain, objects, references, packfiles, refspec, transfer protocols, maintenance/data recovery, environment variables — https://git-scm.com/book/en/v2/Git-Internals-Plumbing-and-Porcelain
11. **Appendix A: Git in Other Environments** — GUIs, VS, VS Code, JetBrains IDEs, Sublime, Bash, Zsh, PowerShell — https://git-scm.com/book/en/v2/Appendix-A:-Git-in-Other-Environments-Graphical-Interfaces
12. **Appendix B: Embedding Git in your Applications** — command-line Git, Libgit2, JGit, go-git, Dulwich — https://git-scm.com/book/en/v2/Appendix-B:-Embedding-Git-in-your-Applications-Command-line-Git
13. **Appendix C: Git Commands** — setup/config, creating projects, snapshotting, branching/merging, sharing, inspection, debugging, patching, email, external systems, administration, plumbing — https://git-scm.com/book/en/v2/Appendix-C:-Git-Commands-Setup-and-Config
