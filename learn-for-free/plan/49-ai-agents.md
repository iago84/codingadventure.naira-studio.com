# Plan for Vol. 49 - AI Agents (Hugging Face)

**Source:** https://huggingface.co/learn/agents-course
**Status:** planned
**Access:** reachable, free (public course pages)

## Approach

Hugging Face's Agents course teaches how to build AI agents using the
Transformers and LangChain ecosystems. This volume covers the same syllabus
with original explanations, self-contained code and exercises that run on CPU
or a free GPU.

## Chapter list

| # | Chapter | Topics |
|---|---------|--------|
| 1 | What is an AI agent? | definition, capabilities, limitations |
| 2 | Tools and tool use | defining tools, calling them from code |
| 3 | Memory and context | short-term and long-term memory |
| 4 | Planning and reasoning | chain of thought, self-consistency |
| 5 | Building a simple agent | from scratch in Python |
| 6 | Evaluation and testing | testing agent behaviour, edge cases |
| 7 | Where to go next | advanced frameworks, production tips |
