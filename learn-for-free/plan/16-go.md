## Learning path (source order)
1. **Hello, World!** — Package main, imports and running your first Go program — https://learn-golang.org/en/Hello%2C_World%21
2. **Variables** — Declaring and initialising variables, basic types and zero values — https://learn-golang.org/en/Variables
3. **Arrays** — Fixed-size sequences and indexing — https://learn-golang.org/en/Arrays
4. **Slices** — Dynamic views over arrays, append and slicing — https://learn-golang.org/en/Slices
5. **Maps** — Key/value dictionaries and lookup patterns — https://learn-golang.org/en/Maps
6. **If-Else** — Conditional branching and comparison — https://learn-golang.org/en/If-Else
7. **Loops** — The single `for` loop form, range iteration — https://learn-golang.org/en/Loops
8. **Functions** — Declaring functions, parameters and return values — https://learn-golang.org/en/Functions
9. **The fmt module** — Printing, formatting verbs and standard output — https://learn-golang.org/en/The_fmt_module
