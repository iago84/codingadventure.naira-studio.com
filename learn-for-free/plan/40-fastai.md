# Plan for Vol. 40 - Fast.ai

**Source:** https://course.fast.ai/
**Status:** planned
**Access:** reachable, free (course pages and notebooks are public)

## Approach

Fast.ai is a free, practical deep learning course built on top of PyTorch.
This volume follows the course's "Practical Deep Learning for Coders" path with
original explanations and self-contained code that reproduces the key ideas
without copying notebooks verbatim.
