# Plan for Vol. 38 - Machine Learning (Kaggle)

**Source:** https://www.kaggle.com/learn/intro-to-ml
**Status:** planned
**Access:** reachable, gated (free account / Kaggle login required)

## Approach

The Kaggle "Intro to Machine Learning" course walks through the core concepts:
features, targets, model evaluation, decision trees, ensembles and
regularisation. This volume covers the same ground with original writing,
original code and a different dataset.
