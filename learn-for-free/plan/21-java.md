## Learning path (source order)
1. **Trails Covering the Basics: Getting Started** — Intro to Java technology + installing JDK and creating a first program — https://docs.oracle.com/javase/tutorial/getStarted/index.html
2. **Trails Covering the Basics: Learning the Java Language** — Essential language concepts: classes, objects, inheritance, datatypes, generics, packages — https://docs.oracle.com/javase/tutorial/java/index.html
3. **Trails Covering the Basics: Essential Java Classes** — Exceptions, basic I/O, concurrency, regular expressions, platform environment — https://docs.oracle.com/javase/tutorial/essential/index.html
4. **Trails Covering the Basics: Collections** — Using and extending the Java Collections Framework — https://docs.oracle.com/javase/tutorial/collections/index.html
5. **Trails Covering the Basics: Date-Time APIs** — The `java.time` API for date and time code — https://docs.oracle.com/javase/tutorial/datetime/index.html
6. **Trails Covering the Basics: Deployment** — Packaging apps in JAR files, deploying with Java Web Start/Plug-in — https://docs.oracle.com/javase/tutorial/deployment/index.html
7. **Trails Covering the Basics: Preparation for Java Programming Language Certification** — List of training/tutorial resources for Oracle certification — https://docs.oracle.com/javase/tutorial/extra/certification/index.html
8. **Creating GUIs: Creating a GUI with Swing** — Comprehensive introduction to GUI creation — https://docs.oracle.com/javase/tutorial/uiswing/index.html
9. **Creating GUIs: Creating a JavaFX GUI** — JavaFX tutorials (offsite Oracle docs) — https://docs.oracle.com/javafx/index.html
10. **Specialized: Custom Networking** — Java platform networking features — https://docs.oracle.com/javase/tutorial/networking/index.html
11. **Specialized: The Extension Mechanism** — Making custom APIs available to all applications — https://docs.oracle.com/javase/tutorial/ext/index.html
12. **Specialized: Full-Screen Exclusive Mode API** — Using graphics hardware for immersive display — https://docs.oracle.com/javase/tutorial/extra/fullscreen/index.html
13. **Specialized: Generics (advanced)** — Type system enhancement for compile-time type safety — https://docs.oracle.com/javase/tutorial/extra/generics/index.html
14. **Specialized: Internationalization** — Adapting software to various languages and regions — https://docs.oracle.com/javase/tutorial/i18n/index.html
15. **Specialized: JavaBeans** — Java component technology — https://docs.oracle.com/javase/tutorial/javabeans/index.html
16. **Specialized: JAXB** — Java Architecture for XML Binding — https://docs.oracle.com/javase/tutorial/jaxb/index.html
17. **Specialized: JAXP** — Java API for XML Processing — https://docs.oracle.com/javase/tutorial/jaxp/index.html
18. **Specialized: JDBC Database Access** — DB connectivity API — https://docs.oracle.com/javase/tutorial/jdbc/index.html
19. **Specialized: JMX** — Java Management Extensions — https://docs.oracle.com/javase/tutorial/jmx/index.html
20. **Specialized: JNDI** — Java Naming and Directory Interface (DNS, LDAP) — https://docs.oracle.com/javase/tutorial/jndi/index.html
21. **Specialized: Reflection** — API reflecting classes, interfaces and objects in the JVM — https://docs.oracle.com/javase/tutorial/reflect/index.html
22. **Specialized: RMI** — Remote Method Invocation — https://docs.oracle.com/javase/tutorial/rmi/index.html
