# Plan for Vol. 44 - LLMs (Hugging Face)

**Source:** https://huggingface.co/learn/llm-course
**Status:** planned
**Access:** reachable, free (public course pages)

## Approach

Hugging Face's LLM course teaches how to work with large language models using
the Transformers library. This volume covers the same syllabus with original
explanations, self-contained code and exercises that run on CPU or a free GPU.

## Chapter list

| # | Chapter | Topics |
|---|---------|--------|
| 1 | What is an LLM? | definition, capabilities, limitations |
| 2 | The Transformers library | installation, pipeline, first model |
| 3 | Tokenisation | tokenisers, vocabularies, special tokens |
| 4 | Model architectures | encoder-only, decoder-only, encoder-decoder |
| 5 | Text generation | sampling, temperature, top-k, top-p |
| 6 | Prompting and fine-tuning | instruction tuning, LoRA |
| 7 | Quantisation | reducing memory, GPTQ, AWQ |
| 8 | Working with the Hub | uploading, sharing, versions |
| 9 | Evaluation | benchmarks, human evaluation, pitfalls |
| 10 | Where to go next | RAG, agents, production deployment |
