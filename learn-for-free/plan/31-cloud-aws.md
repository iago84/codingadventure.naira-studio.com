# Vol. 31 – Cloud (AWS) – Study Plan

- Source site: https://aws.amazon.com/training/ (plus /training/digital/ and /training/ramp-up-guides/)
- Fetched: 2026-10-10
- Access: reachable
- Notes: AWS marketing pages are public; the course catalog itself lives on skillbuilder.aws (free tier covers 900+ self-paced courses, labs/exam prep behind a paid subscription). Only short topic names are used below.

## Learning path (source order)
1. **Cloud Practitioner role track (beginners)** — Cloud fundamentals and best practices for first-time AWS learners — https://skillbuilder.aws/getstarted
2. **Cloud Essentials / Getting Started tutorials** — Step-by-step free tutorials for common AWS tasks — https://aws.amazon.com/getting-started/cloud-essentials/
3. **AWS Skill Builder digital courses (free)** — 900+ self-paced digital courses covering every service and skill level — https://aws.amazon.com/training/digital/
4. **Learn training by role or domain** — Curated tracks for Solutions Architect, Developer, ML/AI, Security, Data Analytics — https://aws.amazon.com/training/learn-about/
5. **Ramp-Up Guides by role** — Curated PDFs: Decision Maker, Developer, DevOps, Solutions Architect, Cloud Operator (SysOps) — https://aws.amazon.com/training/ramp-up-guides/
6. **Practice: hands-on labs & immersive learning** — Lab experiences and real-world scenarios in provisioned AWS environments — https://aws.amazon.com/training/digital/immersive-learning/
7. **Prepare: certification exam prep** — Official exam prep courses, pretests, practice exams — https://aws.amazon.com/certification/certification-prep/
8. **Validate: AWS Certification** — Industry-recognized Cloud Practitioner → Associate → Professional/Specialty exams — https://aws.amazon.com/certification/
9. **Classroom training (live)** — Instructor-led in-person or virtual classes — https://aws.amazon.com/training/classroom/
10. **AWS Educate (free, ages 13+)** — Free self-paced cloud content and labs for pre-professionals — https://aws.amazon.com/education/awseducate/
