## Learning path (source order)

14 official learning paths are advertised on the homepage (source order):

1. **Pre Security** (easy) — Networking, Linux and Windows fundamentals before security — https://tryhackme.com/path/outline/presecurity
2. **Cyber Security 101** (easy) — Entry-level security concepts — https://tryhackme.com/path/outline/introtocybersecurity
3. **CompTIA Pentest+** (easy) — Pentest+ aligned offensive path
4. **Security Engineer** (easy) — Engineering-focused defensive role path
5. **SOC Level 1** (easy) — Security operations centre analyst path
6. **Jr Penetration Tester** (intermediate) — Practical pentesting fundamentals
7. **Offensive Pentesting** (intermediate) — Broader offensive tooling and techniques
8. **Web Application Pentesting** (intermediate) — OWASP-style web attacks
9. **DevSecOps** (intermediate) — Security inside CI/CD and infrastructure
10. **Defending Azure** (intermediate) — Microsoft cloud defence
11. **AI Security** (intermediate) — AI/LLM attack surface
12. **Web Application Red Teaming** (hard)
13. **Advanced Endpoint Investigations** (hard) — Endpoint DFIR
14. **Red Teaming** (hard) — Full adversary simulation

## Flags / issues

- Path outline pages render only navigation shell without login/JavaScript (e.g. /path/outline/presecurity could not be read); the 14 path names and levels come from the public homepage, but room lists inside the paths are not publicly fetchable.
- Much of the content requires a TryHackMe subscription (paywall); only some free rooms are available without an account. Plan therefore leans on the free public paths (Pre Security, Cyber Security 101) plus standard free resources to be referenced by name, not copied: OWASP Top 10 / Cheat Sheets, MITRE ATT&CK, NIST SP 800-53/61, CISA guidance.
- No room text or walkthrough content will be reproduced; TryHackMe material is copyrighted.
