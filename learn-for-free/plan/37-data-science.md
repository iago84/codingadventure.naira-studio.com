# Plan for Vol. 37 - Data Science (Kaggle)

**Source:** https://www.kaggle.com/learn
**Status:** planned
**Access:** reachable, gated (free account / Kaggle login required)

## Approach

The Kaggle "Data Science" micro-course introduces the end-to-end supervised
learning workflow on a real dataset (Titanic survival prediction). This volume
covers the same workflow with original explanations, self-contained code and a
different dataset so nothing is copied.

## Chapter list

| # | Chapter | Topics |

| 1 | What is data science? | roles, workflow, the lifecycle |
| 2 | Machine learning refresher | prediction, features, labels, training |
| 3 | Your first Kaggle notebook | the Titanic dataset, loading, inspection |
| 4 | Predicting survival | a first model, baseline, evaluation |

| 12 | Modelling with trees | decision trees, overfitting, pruning |
| 13 | Ensembling | random forests, why they work |
| 14 | Where to go next | more Kaggle courses, competitions |

## Fallback

All content is original writing. The Titanic dataset is used only as a
reference for the workflow; all examples use a different dataset (e.g. a
synthetic or public-domain dataset) so no data or code is copied.
