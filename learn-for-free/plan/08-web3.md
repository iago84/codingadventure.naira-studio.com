## Learning path (source order)
NOTE: This list is inferred/standard Web3 curriculum (LearnWeb3's published beginner-to-advanced structure plus common free official docs); the live platform TOC could not be retrieved. Verified anchor docs follow each item.
1. **Web3 / blockchain fundamentals** — decentralization, blocks, transactions, wallets, gas, public-key cryptography — inferred; see https://ethereum.org/en/web3/ and https://ethereum.org/en/whitepaper/
2. **Ethereum basics: accounts, EVM, clients, networks** — testnets, faucets, reading chain data — inferred; see https://ethereum.org/en/developers/docs/intro-to-ethereum/
3. **Solidity programming** — syntax, types, functions, mappings, structs, events, inheritance — inferred; see https://docs.soliditylang.org/
4. **Smart contract development with Hardhat/Foundry** — compiling, deploying to local and test networks — inferred; see https://hardhat.org/tutorial and https://book.getfoundry.sh/
5. **Token standards: ERC-20, ERC-721 (NFT), ERC-1155** — writing your own tokens — inferred; see https://ethereum.org/en/developers/docs/standards/tokens/
6. **Front-end dApp integration (ethers.js / viem / web3.js)** — connecting wallets, calling contracts, sending transactions — inferred; see https://docs.ethers.org/ and https://viem.sh/
7. **Indexing and storage (The Graph, IPFS)** — reading contract events, decentralized file storage — inferred; see https://thegraph.com/docs/ and https://docs.ipfs.tech/
8. **Advanced contracts: proxies/upgradeability, security patterns** — reentrancy, checks-effects-interactions — inferred; see https://ethereum.org/en/developers/docs/smart-contracts/security/
9. **DeFi and DAO primitives** — swaps, lending, governance contracts — inferred; see https://ethereum.org/en/defi/
10. **Testing and deploying to mainnet** — unit tests, verification, block explorers — inferred; see https://hardhat.org/hardhat-runner/docs/other/test
11. **Another chain / Solana track** (optional second-language ecosystem) — accounts model, Anchor, SPL tokens — inferred; see https://solana.com/docs and https://www.anchor-lang.com/
